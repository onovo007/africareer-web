# Images

Drop your hero photo here as **`hero.jpg`** (or `hero.png`). The landing page blends it
behind a brand gradient automatically. Without it, a clean gradient placeholder shows.

Recommended aspect ratio: ~16:8 (wide), at least 1600px wide.

## Use only commercially-licensed images
For this commercial product, use images that are **free for commercial use with no
attribution**:
- Unsplash — https://unsplash.com  (search: "African students", "African youth university")
- Pexels — https://pexels.com

Avoid "free" stock that requires attribution or a subscription (e.g., some Freepik images)
unless you hold a valid license.
